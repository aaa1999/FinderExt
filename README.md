# FinderExt — Finder 右键增强工具

给 macOS Finder 的右键菜单**追加**两个功能（与 Finder 原生菜单合并显示，不修改、不覆盖任何原有菜单项）：

- **在此打开终端**：在任意文件夹空白处、选中的文件夹、或选中文件所在文件夹打开 Terminal.app
- **新建文件…**：弹出小输入框，输入完整文件名（含后缀，如 `note.md`、`脚本.py`，后缀任意自定义），回车即在当前文件夹创建空文件，并在 Finder 中选中新文件

## 架构

```
┌─────────────────────┐  右键点击菜单项   ┌──────────────────────────┐
│ FinderExtExtension  │ ───────────────▶ │ FinderExt.app（菜单栏常驻）│
│ (Finder Sync 扩展)   │  finderext://    │ 执行：打开终端/建文件/定位  │
└─────────────────────┘  URL 或分布式通知  └──────────────────────────┘
```

- 扩展监听根目录 `/`，任何文件夹右键都会出现菜单项
- 宿主 App 常驻菜单栏（不占 Dock），通过自定义 URL Scheme 接收命令；未运行时会被系统自动拉起
- 宿主默认注册为登录项（可在菜单栏图标中关闭）

## 安装

```bash
./scripts/build-and-install.sh
```

脚本会：XcodeGen 生成工程 → xcodebuild 编译 → 安装到 `/Applications` → 启动。

## 启用扩展（装完后必做一次）

1. 打开 **系统设置 → 通用 → 登录项与扩展 → 扩展 → Finder 扩展**
   （或从菜单栏图标 → 「启用 Finder 扩展…」直达）
2. 打开 **FinderExt** 的开关
3. 回到 Finder，在任意文件夹内右键验证

## 权限说明（均为可选，按需授予）

| 权限 | 用途 | 不授权的后果 |
|---|---|---|
| Finder 扩展开关 | 右键菜单出现新条目 | 完全无功能 |
| 自动化 →「控制 Finder」（首次建文件时弹一次） | 让 Finder 代建文件，**任何文件夹都不再逐个弹授权** | 回退为本应用直接创建，每次遇到新文件夹会弹 macOS 的文件夹授权 |
| 辅助功能（设置 → 隐私与安全性） | 新建文件后自动进入重命名 | 文件仍会创建并选中，需手动按回车重命名 |

> macOS 26+ 对应用写入文件夹采用“按文件夹”授权弹窗。FinderExt 的两个功能都已绕开该机制：
> - **新建文件**：让 Finder 代建文件（文件系统操作全部由 Finder 完成），全局只需一次「控制 Finder」自动化授权
> - **打开终端**：通过一次性 `.command` 脚本（放在本应用缓存目录、执行后自删），目标文件夹仅由 shell `cd` 进入，不作为文档传给终端，无文件夹授权弹窗

## 菜单栏选项

- **启用 Finder 扩展…**：直达系统设置扩展页
- **开机自动启动**：默认开启，保证右键功能随时可用
- **新建文件后自动重命名**：默认开启，可关闭

## 常用命令

```bash
# 更换终端：.command 由系统默认处理应用执行，
# 在 Finder 里右键任一 .command 文件 → 显示简介 → 打开方式 可修改全局默认（如 iTerm）

# 卸载
pkill -x FinderExt; rm -rf /Applications/FinderExt.app
# 然后在 系统设置 → 通用 → 登录项与扩展 中移除登录项与扩展
```

## 开发

- 工程由 `project.yml`（XcodeGen）生成，`FinderExt.xcodeproj` 不入库，改完配置执行 `xcodegen generate`
- 两个 target 均为本地自用配置：非沙盒、ad-hoc 签名，无需开发者账号
- 源码：`App/`（宿主）、`Extension/`（Finder 扩展）
